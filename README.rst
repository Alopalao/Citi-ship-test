Citi ship Test
**************

Description
###########
Very simple application for android phones that shows questions from the citizenship test. The order is random and the answers are hidden behind the press of a button.

Why?
####
I had to take the citizenship exam myself and I am lazy to write the 100 questions into cards. But I am faster writing code so I made this very simple app.

Want it?
########

Feel free to copy this repo. Do not need any mentioning, just copy it.
Modify the questions if they have changed, the list of questions is on every.txt_ (inside ``/app/src/main/assets/``).

.. _every.txt: https://github.com/Alopalao/Citi-ship-test/blob/main/app/src/main/assets/every.txt
